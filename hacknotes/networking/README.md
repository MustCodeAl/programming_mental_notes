## Defense Against Network Attack
In defending against network attack, there are broadly speaking four sets of available tools:

1. **Management** — keeping your systems up-to-date and configured in ways that will minimise the attack surface.
2. **Filtering** — the use of firewalls to stop bad things like Trojans and network exploits, and to detect signs of attack and compromise if anything gets through.
3. **Intrusion Detection** — having programs monitoring your networks and machines for signs of malicious behaviour.
4. **Encryption** — protocols such as TLS and SSH that enable you to protect specific parts of the network against particular attacks.


# Networking Fundamentals

## Key Networking Concepts

### 1. Network Types

- **LAN (Local Area Network)**:
  - Connects devices in a small area (home, office)
  - High-speed connectivity
  - Examples: Home WiFi, Office network
- **WAN (Wide Area Network)**:
  - Covers large geographical areas
  - Connects multiple LANs
  - Example: Internet
- **MAN (Metropolitan Area Network)**:
  - Covers a city or large campus
  - Intermediate between LAN and WAN

### 2. Network Layers (OSI Model)

1. Physical Layer
2. Data Link Layer
3. Network Layer
4. Transport Layer
5. Session Layer
6. Presentation Layer
7. Application Layer

### 3. Key Protocols

- **TCP/IP**: Core internet communication protocol
- **HTTP/HTTPS**: Web communication
- **DNS**: Domain name resolution
- **SMTP**: Email sending
- **FTP**: File transfer

### 4. Network Devices

- **Router**: Connects different networks
- **Switch**: Connects devices within a network
- **Modem**: Converts digital signals to analog
- **Firewall**: Network security protection

### 5. Network Security

- Encryption
- Firewalls
- VPN (Virtual Private Network)
- Two-factor authentication
- Regular security updates

### 6. Wireless Networking

- **WiFi Standards**: 
  - 802.11ac
  - 802.11ax (WiFi 6)
  - 802.11be (WiFi 7)

### 7. Best Practices

- [ ] Use strong passwords
- [ ] Keep software updated
- [ ] Use VPN on public networks
- [ ] Implement network segmentation
- [ ] Regular security audits

### 8. Troubleshooting Tips

- Check physical connections
- Restart networking equipment
- Verify IP configurations
- Use `ping` and `tracert` commands
- Check for IP conflicts
